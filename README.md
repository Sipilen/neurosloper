# Нейрослопер

Локальный веб-сервис для превращения обычных фотографий в аутентичный AI slop (фото и видео) с помощью локальной диффузии (`diffusers`) и VLM-подсказок (`BLIP`).

## Возможности

### Фото-слоп (`POST /api/slopify`)
- **Полная хуйня (Думающий бред)** — BLIP дважды всматривается в изображение с абсурдными затравками, добавляет случайный сюрреалистичный твист, пережимает картинку и прогоняет через диффузию с высоким `guidance_scale`. Ход «мыслей» выводится в интерфейс.
- **Пластиковый HDR** — глянцевая восковая кожа и пересвеченный 8K-контраст.
- **Галлюцинации 2022** — поплывшие детали, лишние конечности и искажения.
- **Испорченный телефон** — BLIP пытается угадать содержимое фото, а генератор перерисовывает его по этому описанию.
- **Глубокая прожарка (×3)** — три последовательных прогона `img2img` с накоплением артефактов.
- **Дешёвый аниме-слоп** — кислотный аниме-фильтр.

### Видео-слоп (`POST /api/slopify-video`)
- **Эволюция бреда (Морфинг)** — покадровый рекурсивный зум/сдвиг на `sd-turbo`, где BLIP каждые 5 кадров заново придумывает описание.
- **Бесконечный зум в слоп** — плавное приближение внутрь кадра с нарастающими галлюцинациями.
- **Вращение в бездну** — зум с поворотом и пережаром цветов.
- **AnimateDiff (Видео-диффузия)** — генерация до 32 кадров через `AnimateDiffVideoToVideoPipeline` с `enable_model_cpu_offload()` под 8 ГБ VRAM.

### Дополнительно
- Загрузка фото перетаскиванием, кликом или через `Ctrl+V`.
- Рекурсивная кнопка **«Заслопить ещё раз»** и сброс к исходнику.
- Тумблеры **«Пережать шакалами»** (JPEG-артефакты) и **«Глитч-сдвиг RGB каналов»**.
- Фиксация `Seed` и лента истории последних генераций в сессии.
- Экспорт результатов в `PNG` и `MP4` (`libx264`).

## Требования

- Python 3.10+ (проверено на Python 3.13)
- NVIDIA GPU с поддержкой CUDA (рекомендуется от 8 ГБ VRAM; на CPU работает значительно медленнее)

## Установка и запуск (Windows)

1. Клонируйте репозиторий и перейдите в папку проекта:
   ```bash
   git clone <url-вашего-репозитория>
   cd slop
   ```

2. Создайте виртуальное окружение (например, через `uv` или стандартный `venv`):
   ```powershell
   python -m venv .venv
   ```

3. Установите PyTorch с CUDA (пример для CUDA 12.6):
   ```powershell
   .venv\Scripts\pip.exe install torch torchvision --index-url https://download.pytorch.org/whl/cu126
   ```

4. Установите остальные зависимости:
   ```powershell
   .venv\Scripts\pip.exe install -r requirements.txt
   ```

5. Запустите сервер:
   - Двойным кликом по `run.bat`, либо командой:
     ```powershell
     .venv\Scripts\python.exe app.py
     ```
   - Откройте в браузере `http://127.0.0.1:8000`.

## Используемые модели

При первом запуске соответствующих режимов веса автоматически скачиваются с Hugging Face в локальный кэш:
- `stabilityai/sd-turbo` — базовая модель для фото-слопа и морфинг-видео.
- `Salesforce/blip-image-captioning-base` — модель описания изображений для режимов «Испорченный телефон», «Полная хуйня» и видео.
- `stable-diffusion-v1-5/stable-diffusion-v1-5` и `guoyww/animatediff-motion-adapter-v1-5-2` — для режима AnimateDiff.

Можно переопределить модели через переменные окружения `SLOP_MODEL_ID`, `SLOP_CAPTION_MODEL_ID`, `SLOP_ANIM_BASE_MODEL_ID`, `SLOP_ANIM_ADAPTER_ID`.
